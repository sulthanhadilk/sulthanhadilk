### 👨‍💻 About Me

Hello! I am **Sulthan Hadil K**, a passionate **Full-Stack Developer** dedicated to engineering reliable, scalable, and intuitive web applications. My development work centers on modern JavaScript/TypeScript ecosystems, high-performance real-time architectures, and integrating machine learning capabilities into real-world applications.

- 🚀 **Full-Stack Craftsmanship:** Specialized in the **MERN** stack (MongoDB, Express.js, React, Node.js) with production-ready security, modular architectures, and clean API design.
- ⚡ **Real-Time Architect:** Proven experience designing low-latency communication networks using **LiveKit (WebRTC)** and **WebSockets** for multi-user video and instant messaging systems.
- 🤖 **AI & Vision Integration:** Experienced in deploying browser-based machine learning with **TensorFlow.js** and generative AI workflows via **OpenAI APIs**.
- 🛠️ **Engineering Standards:** Strong advocate for clean code, responsive design, modern UI toolkits (Tailwind CSS, Framer Motion), and containerized deployments with Docker.
- 🎯 **Looking For:** Impactful full-stack engineering roles, collaborative open-source projects, and cutting-edge web development challenges.
